Introduction To CSS

CSS stands for Cascading Style Sheets

Why Do We Need CSS

CSS is used to define the layout and visual style of web pages.

Basic CSS Properties

  1. Color : Controls the FOreground colour of the selected html element
  2. Background-Color : Controls the Background colour of the selected html element
  3. Font-size: Controls the size of the text.
  4. Margin: Creates space outside the border of an element.
  5. Padding: Generates space inside an element, between the content and the border.

CSS learning Goals

  1. Master the use of Flexbox and CSS Grid for creating responsive layouts.
  2. Understand how to implement CSS variables to create clean and maintainable stylesheets.
  3. Learn how to create smooth animations and transitions to enhance user interaction.
