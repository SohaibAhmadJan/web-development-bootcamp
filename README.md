## 🚀 How to Run Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SohaibAhmadJan/web-development-bootcamp.git
   ```

2. **Navigate to the folder:**
   ```bash
   cd web-development-bootcamp
   ```

3. **Open any task in your browser:**
   Open any `index.html` directly in your browser or use the VS Code **Live Server** extension.
